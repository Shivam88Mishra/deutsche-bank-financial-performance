# Deutsche Bank Financial Performance Analysis

## 📊 Overview
This project analyzes and forecasts Deutsche Bank's financial performance using Python.  
It focuses on KPI generation, trend visualization, and predictive modeling to understand financial stability and growth.

---

## 🧩 Objectives
- Perform financial data cleaning and preprocessing  
- Generate key financial KPIs  
- Build forecasting models for future revenue prediction  
- Visualize performance trends

---

## 🛠️ Tools & Libraries
- **Python**, **Pandas**, **NumPy**
- **Matplotlib**, **Seaborn**
- **Scikit-Learn**, **Prophet**

---

## ⚙️ Key Steps
1. **Data Cleaning:** Removed symbols, missing values, and converted columns to numeric.  
2. **Feature Engineering:** Created lag and rolling features (6M, 12M).  
3. **KPI Calculation:** Revenue Growth (YoY), ROA, Net Income Margin, etc.  
4. **Forecasting Models:**  
   - Random Forest Regressor  
   - Prophet Forecast Model  
5. **Visualization:** Time-series plots for trend insights.

---

## 📈 Results
- Built reliable KPI trends and insights over 12 months  
- Developed Prophet-based revenue forecast model  
- Achieved realistic financial metric interpretation for analysis
